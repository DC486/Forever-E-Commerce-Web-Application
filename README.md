# Forever-E-Commerce-Web-App
## 🛒 Full Stack E-Commerce Website (MERN + Stripe + Razorpay)

This project is a full-stack E-Commerce application built with the MERN stack (MongoDB, Express.js, React.js, Node.js) and integrated with Stripe & Razorpay payment gateways. It delivers a complete online shopping experience where users can explore products, filter and sort them, choose variants such as size, add items to the cart, and place orders using Cash on Delivery or online payments.

The application includes secure authentication using JWT, delivery address management, and order history for users. On the admin side, an admin dashboard allows product uploads, updates, deletions, user management, and order tracking. The backend APIs are built with Node.js and Express.js, and all data — products, users, and orders — is stored in MongoDB. The frontend is built with React.js and styled using TailwindCSS/Bootstrap, providing a modern, responsive, and user-friendly design.

## 🔑 Features

- User authentication and authorization (JWT)

- Product browsing, filtering, and sorting

- Shopping cart with product variants

- Checkout with multiple payment options: COD, Stripe, Razorpay

- Order history and delivery address management

- Admin dashboard for product, user, and order management

- RESTful backend APIs

- Fully responsive design

## 🧑‍💻 Tech Stack

- Frontend: React.js, React Router, TailwindCSS/Bootstrap

- Backend: Node.js, Express.js

- Database: MongoDB

- Authentication: JWT

- Payments: Stripe & Razorpay
